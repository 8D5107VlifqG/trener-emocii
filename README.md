# Тренажёр эмоций

Офлайн-приложение для Android (Capacitor). Список эмоций вшит в `www/index.html`.

## Получить APK
1. Откройте вкладку **Actions** в репозитории.
2. Выберите последний запуск **Build APK** (или нажмите **Run workflow**).
3. Внизу страницы запуска в разделе **Artifacts** скачайте `trenazher-emociy-apk`.
4. Распакуйте zip, перенесите `app-debug.apk` на телефон и установите
   (разрешите установку из неизвестных источников).

## Изменить список
Эмоции лежат в `www/index.html` в переменной `DEFAULT_ITEMS`.
После правки сделайте commit: APK пересоберётся сам.
